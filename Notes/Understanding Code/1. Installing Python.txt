py -3.13 -c "import sys; print(sys.executable)"
- py is Window's Python Launcher. It finds the installed Python version
- -3.13 tells the launcher use Python 3.13 specifically
- -c means run this little piece of Python code directly from Terminal
- import sys loads Python's built-in sys module, which contain information about the Python environment
- sys.executable contains the exact path to the Python executable currently running
- print(...) prints that exact path to the terminal

pip --version
- This checks whether Python's Package Installer is installed and accessible and tells which version you're using
- Python doesn't include every library we'll need
- Instead of manually downloading each library, we use pip, e.g. pip install flask

node --version
- It tells which version of Node.js is installed and being used

npm --version
- It tells which version of npm (Node Package Manager) is installed
